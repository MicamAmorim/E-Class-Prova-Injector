1. Arquivo da prova

A lista será preenchida mesmo se a consulta de detalhes falhar; nesse caso, a data de criação ficará como não verificada. É possível ampliar o período até 365 dias. Provas ativas ou com respostas não podem ser alteradas.

Turmas já vinculadas à prova

Escolha uma prova para carregar as turmas registradas no E-Class. Até confirmar as permissões, a seleção local ficará bloqueada.

Selecione a pasta da prova para carregar imagens automaticamente, inclusive das alternativas.

Nenhum arquivo analisado.

2. Destino

Para uma prova já criada, as turmas serão consultadas no E-Class. A seleção abaixo é apenas informativa.

Modelo de público individual validado (obrigatório para envio real)

Por segurança, a extensão não presumirá a estrutura de destinatários individuais: se o portal ignorar um campo desconhecido, a prova poderia atingir toda a turma. Forneça um objeto JSON compatível com o público individual de uma turma, obtido de uma aplicação oficial. Variáveis aceitas: {{turma_id}}, {{entidade_id}}, {{alunos_ids}}, {{alunos_objetos}}.
